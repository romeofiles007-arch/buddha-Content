# ธรรมะ Auto — ธีมตามหมวดและภาพผู้ใหญ่

สถานะ: ข้อกำหนดแก้ไขจากผู้ใช้โดยตรง 2026-10-30 ดำเนินการต่อจากธีมที่ส่งมอบ

ผู้ใช้ต้องการให้สลับหมวดทั้งสามแล้วเปลี่ยนธีมทั้งหมด และปฏิเสธความเป็นเด็กทุกส่วน ข้อกำหนดนี้แทนที่เณรน้อย ตัวละคร chibi และบรรยากาศน่ารักที่เลือกก่อนหน้า คง 12 เฟรมต่อคน และใช้ 3D สัดส่วนผู้ใหญ่สมจริง สุขุม สำรวม ไม่มีหัวโต ตาโต หรือภาพเด็ก

## การสลับธีม

- `buddha` — หมวดพุทธประวัติและพุทธพจน์: พุทธสถาน พระพุทธรูป ต้นโพธิ์ หินทรายและทองสงบ
- `monk` — หมวดพระเกจิอาจารย์: วัดป่า กุฏิไม้ คัมภีร์ สีป่าเขียวและไม้เก่า ไม่สร้างภาพเหมือนพระเกจิบุคคลจริงโดยไม่มีต้นฉบับ
- `dhamma` — หมวดธรรมะสำหรับพุทธศาสนิกชน: ลานปฏิบัติธรรม ธรรมจักร บัว สีงาช้าง เขียวมะกอก และดินเผา
- `mix` เดิมยังคงอยู่ ใช้ธีมธรรมะกลางที่สุขุม ไม่สุ่มธีมเอง

ทั้งสามเป็นธีมสถานที่และสัญลักษณ์ที่แตกต่างจริง มีฉากสว่าง/มืดแยกกัน เปลี่ยนพื้นหลัง แบนเนอร์ โทนสีพื้น/ปุ่ม/ขอบ/สถานะตกแต่ง โลโก้ในแอป favicon หน้าต่างย่อย และกล่องตั้งค่า คงสีที่สื่อความสำเร็จ/ข้อผิดพลาดตามหน้าที่

ตัวเลือกหมวดแสดงชัดและใช้ได้ทั้งโหมดพิมพ์เอง เสนอหัวข้อ และเลือกอัตโนมัติ เมื่อเลือกเปลี่ยนธีมทันทีและใช้ค่าที่บันทึกกลับมาเมื่อเปิดใหม่ ไม่ให้การเปลี่ยนแผนกทับธีมหมวด

## ทีมงาน

ใช้ภาพ 3D แบบผู้ใหญ่สัดส่วนธรรมชาติ: พระภิกษุนักเรียบเรียงอายุประมาณ 45–55 ปี และผู้ใหญ่ทำงานศิลป์ จัดฉาก เสียง และตัดต่อ ไม่มีเณรน้อยหรือหน้าตาแบบตุ๊กตา ภาพแต่ละคนเป็น atlas 4×3 พื้นโปร่งใส 12 ท่าทำงานต่อเนื่อง คง ID ของบริการและพฤติกรรมเล่น/หยุดเดิม ใช้ทีมผู้ใหญ่ร่วมกันทั้งสามหมวดเพื่อคงความหมายของแผนก ส่วนฉากและระบบสีเปลี่ยนทั้งแอปตามหมวด

## ขอบเขตและทางเลือก

ผู้ใช้ระบุทิศทางแล้ว จึงใช้หมวดเนื้อหาเดิมเป็นต้นทางของธีม ไม่เพิ่มเมนูเลือกธีมแยกซึ่งอาจขัดกับหมวดที่กำลังใช้ ไม่เปลี่ยน prompt เนื้อหา การผลิตคลิป บัญชี ราคา หรือเรียก API เสียเครดิต

คงไอคอนหลักวัด–ธรรมจักร/.ico เดิมซึ่งไม่มีความเป็นเด็ก เพิ่มสัญลักษณ์ SVG ประจำหมวดในแอป ใช้ฟอนต์ไทยในเครื่องและไม่เพิ่ม dependency ระหว่างใช้งาน

## ตรวจรับ

ตรวจค่าหมวดทั้ง ID และชื่อเดิม การบันทึก/เปิดใหม่ โหมดพิมพ์เอง การเปลี่ยนแผนกแล้วธีมไม่ถูกทับ ทั้ง 3 หมวด × 2 ธีม × 360/450px ตรวจส่วนย่อย representative 12 เฟรมจริง 5 คน ความชัดข้อความ และการหยุดภาพเมื่อซ่อน/พ้นจอ/reduced-motion ใช้ fixture โดยไม่สร้างหรือโพสต์คลิปจริง
