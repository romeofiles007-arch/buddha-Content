# ธรรมะ Auto — ธีมวัดไทย 3D อบอุ่น

สถานะ: ผู้ใช้ยืนยัน “สร้างสิ” — สร้างและตรวจธีมแล้ว 2026-10-30

## สิ่งที่ผู้ใช้เลือก

- ตกแต่งทั้งแอปเป็นธีมศาสนาพุทธและวัด
- ใช้แนววัดไทย 3D อบอุ่น มีเณรน้อยและผู้ช่วยในวัด
- ภาพเคลื่อนไหว 12 เฟรมต่อตัวละคร ครบทั้ง 5 แผนก
- สร้างไอคอนที่เหมาะกับธีมและไฟล์ .ico (ทำและตรวจไฟล์แล้ว)

## เป้าหมาย

ให้แอปทำคลิปภาษาไทยมีบุคลิกเป็นสตูดิโอสื่อธรรมะในวัดไทย อ่านสถานะและเริ่มงานได้ชัดเจน ภาพบรรยากาศและตัวละครเป็น 3D จริง ไม่ใช้ภาพทะเลหรือสัตว์ทะเลเดิมบนหน้าจอที่ส่งมอบ

## แนวทางที่พิจารณา

1. วัดไทย 3D อบอุ่น: ฉากวัดและทีมงานมีมิติ เหมาะกับแอนิเมชัน 12 เฟรม ต้องสร้างภาพชุดใหม่ — ผู้ใช้เลือกแนวนี้
2. วัดไทยลายเส้น: ภาพเรียบและเบากว่า แต่ให้บุคลิกต่างจากแนว 3D ที่ผู้ใช้เลือก

## ภาพและสีที่เสนอ

- ฉากวัดไทย มีศาลา หลังคาวัด เจดีย์ ทางเดินหิน และบัว บรรยากาศสงบ ไม่อัดรายละเอียดไว้ใต้ข้อความ
- ธีมสว่าง: ครีมกระดาษ งาช้าง ทอง และสีจีวรเข้ม
- ธีมมืด: น้ำตาลไม้เข้ม ทองอุ่น งาช้าง และแสงโคมในวัด
- ใช้ไอคอนวัด–ธรรมจักรที่สร้างแล้ว: พื้น #8f301d, ทอง #f4ca78, งาช้าง #fff5db
- สีของแผนกเป็นเฉดในโลกเดียวกัน มีป้ายชื่อและเส้นขอบบอกการเลือก ไม่อาศัยสีเพียงอย่างเดียว
- ชุดฟอนต์ไทยในเครื่องตามระบบเดิม ไม่โหลดฟอนต์ สคริปต์ หรือภาพจากภายนอกระหว่างใช้งาน

## ทีมงาน 5 แผนกที่เสนอ

| แผนกเดิม | ตัวละครใหม่ | งานและท่าทางในภาพเคลื่อนไหว |
| --- | --- | --- |
| ChatGPT — เขียนบทและกำกับภาพ | เณรนักเล่าเรื่อง | เขียนสมุดที่โต๊ะไม้เตี้ย พลิกสายตาระหว่างสมุดกับผู้ใช้ |
| Google Flow — วาดภาพ | ช่างศิลป์ประจำวัด | วาดภาพบัวบนขาตั้ง ขยับมือวาดอย่างนุ่มนวล |
| Kie API — แอนิเมชัน | ผู้ช่วยจัดฉาก | ตรวจลำดับภาพที่อุปกรณ์ทำแอนิเมชัน |
| เสียงพากย์ | อาสานักพากย์ | อ่านบทกับไมโครโฟน ขยับปากและมือเล็กน้อย |
| ตัดต่อ | ผู้ช่วยตัดต่อ | จัดภาพและเสียงที่คอมพิวเตอร์ ขยับมือทำงาน |

รายละเอียดเครื่องแต่งกาย อุปกรณ์ สีประจำคน และจังหวะรอบภาพเป็นการตัดสินใจของผู้ทำ โดยยึดบรรยากาศวัดไทยที่อบอุ่นและบุคลิกสุภาพ

## สัญญาภาพเคลื่อนไหว 12 เฟรม

- ตัวละครแต่ละคนมีภาพ 12 ท่าต่อเนื่องที่สร้างขึ้นจริง รวม 60 เฟรม ไม่เพิ่มจำนวนด้วยการทำสำเนาเฟรมเดิม
- ใช้ sprite atlas โปร่งใส 4 คอลัมน์ × 3 แถว ช่องเท่ากัน เรียงซ้ายไปขวาและบนลงล่าง
- แสดงด้วย CSS แบบเปลี่ยนตำแหน่งภาพครบ 12 ช่อง ไม่เลื่อนผ่านช่องว่าง ไม่กระโดดข้ามแถว
- ใช้ท่าเริ่มต้นนิ่งเมื่อว่าง รอคิว หรือออฟไลน์ และเล่นรอบภาพทำงานเมื่อ working
- หยุดภาพเคลื่อนไหวเมื่อแผงถูกซ่อนหรือพ้นจอ และแสดงภาพนิ่งเมื่อ prefers-reduced-motion
- สถานะ เวลา และรายละเอียดงานยังเป็นข้อความจริงและอัปเดตตามระบบเดิม

## ขอบเขตหน้าจอ

- ปรับแบนเนอร์ ฉากพื้นหลัง ตัวละคร แถวเลือกทีม แถบทีมลอย และตราแอป
- ปรับกล่องโปรเจกต์ โหมดอัตโนมัติ ตั้งค่าแผนก ขั้นทำงานเอง ปุ่ม ช่องกรอก และสถานะต่าง ๆ
- ปรับคลังวิดีโอ หน้าตรวจความพร้อม หน้าต่างยืนยัน/ดูวิดีโอ และหน้าโพสต์อัตโนมัติ รวมไอคอนนกเดิมในส่วนโพสต์
- เปลี่ยนป้ายชื่อสัตว์ทะเลที่แสดงใน UI ให้ตรงกับทีมงานใหม่ ใช้ชื่อแผนกและบริการจริงต่อไป
- ใช้ฉากกลางวันและกลางคืนร่วมกันทั้งแอป แยกแผนกด้วยตัวละคร สีเน้น และป้ายชื่อ การใช้ภาพวัดร่วมกันแทนภาพแยกทุกแผนกเป็นข้อเสนอของผู้ทำ
- ถอดของตกแต่งทะเลออก และใช้พื้นที่ข้างตัวละครให้แสดงสถานะได้ชัด ภาพวัดเป็นองค์ประกอบหลักของบรรยากาศ

## ข้อจำกัดและสิ่งที่คงเดิม

- คงความสามารถทำคลิป การส่งงาน การตั้งค่า และการอ่านสถานะเดิม ไม่เปลี่ยน bridge หรือ pipeline
- คงชื่อและตัวระบุภายในของบริการ เช่น chatgpt, flow, meta, voice, edit เพื่อให้การส่งงานทำงานต่อได้
- ไม่อ่านหรือเปลี่ยน .env หรือ settings_local.json เพื่อการตกแต่ง
- คงการถามสถานะทุก 3 วินาทีและหยุดถามเมื่อ document.hidden
- ไม่เปิด Kie API หรือฟังก์ชันที่เสียเครดิตจากการเปลี่ยนธีม
- ไม่เพิ่ม framework หรือ dependency ที่ต้องโหลดตอนใช้งาน
- รองรับแผง 360–450px ทั้งธีมสว่างและมืด รวมหน้าต่างที่กว้างกว่า
- โครงการนี้ไม่มี Git repository จึงเก็บไฟล์สำรองใน .impeccable/backups ก่อนแก้ไขแทนการใช้ commit

## การสร้างและส่งมอบ

- สร้างภาพฉากวัด 2 ภาพ (สว่าง/มืด) และ sprite atlas 5 ชุดด้วยเครื่องมือ ImageGen ในตัว เก็บไฟล์ใน extension และบันทึกที่มาภาพ
- ไฟล์ .ico มีขนาด 16, 24, 32, 48, 64, 128 และ 256 พิกเซลในไฟล์เดียว พร้อม SVG และ PNG ของไอคอน
- ตรวจเฟรมจริงครบ 12 ช่อง ภาพโปร่งใส อัตราส่วนภาพ และการเรียงลำดับเฟรม
- ตรวจภาพหน้าจอที่ความกว้าง 360 และ 450px ทั้งสองธีม รวมหน้าต่างสำคัญ สถานะทำงาน รอ ออฟไลน์ และลดการเคลื่อนไหว
- ตรวจ syntax และชุดตรวจที่เกี่ยวข้องกับรูปภาพ ไอคอน และการแสดงสถานะ โดยไม่สั่งผลิตคลิปจริง
- อัปเดต PRODUCT.md, DESIGN.md และข้อกำหนดหน้าจอให้ตรงกับธีมที่ส่งมอบ

## งานนอกขอบเขต

ไม่เปลี่ยน prompt สำหรับเนื้อหาคลิป โมเดลเสียง ราคา บัญชี การเชื่อมต่อ การโพสต์จริง หรือสร้างคลิปเพื่อทดสอบธีม
